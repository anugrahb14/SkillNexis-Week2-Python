# Skill Nexis - Python Week 2

This repository contains the Python Week 2 assignments and the Student Management System mini project completed for the Skill Nexis Python Programming Internship.

## Week 2 - Data Structures & File Handling

### Topics Covered

- Lists
- Tuples
- Sets
- Dictionaries
- Reading and Writing Text Files
- CSV
- JSON
- Exception Handling

## Assignments

### 1. Contact Book using Dictionary

A menu-driven contact book that supports:

- Add contacts
- Search contacts
- Update contacts
- Delete contacts

File:
`contact_book.py`

### 2. Word Counter from Text File

Reads a text file and counts:

- Number of words
- Number of lines
- Number of characters

Files:
- `word_counter.py`
- `sample.txt`

### 3. JSON File Reader

Loads student information from a JSON file and displays it in a formatted manner.

Files:
- `json_file_reader.py`
- `students.json`

## Mini Project

### Student Management System

A CSV-based student management system that supports:

- Add student
- Search student
- Delete student
- Store roll number, name, and marks
- Permanently save changes to the CSV file

Files:
- `student_management_system.py`
- `students.csv`
